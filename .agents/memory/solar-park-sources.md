---
name: Solar park source interpretation
description: How to reconcile the supplied park directory with engineering drawings.
---

Use the supplied Solar Parks List for directory capacities and client allocations. Preserve engineering drawings' own labels and capacity units separately; do not silently substitute drawing values into the directory or assign drawings to named parks without evidence.

**Why:** The supplied list and layouts use different scopes and AC/DC values. Some drawings name a company or site rather than a park, so matching them by approximate capacity can misrepresent the portfolio.

**How to apply:** When adding or revising park information, distinguish client allocations from drawing specifications, and request clarification if an exact park-to-layout association is needed.
